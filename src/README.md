# Source Files

This folder contains the editable OpenSCAD source/design files for the cap wall mount system.

## Contents

- `cap-wall-mount.scad` — Parametric wall mount for displaying baseball caps.
- `standoff-tube.scad` — Cylindrical spacer tube for plexiglass panel standoffs.

## Purpose
- Keep the original, editable project files separate from published/exported files.
- Preserve your working design history and tool-specific assets.
