# Cap Wall Mount – Hat Display System

A 3D-printable wall mount for displaying baseball caps and hats in a grid/matrix arrangement on a wall for easy display and selection.

## Features

- **Parametric design** — all dimensions adjustable at the top of the file.
- **FDM-friendly** — designed for printing without supports.
- **Grid-ready** — mount multiples in a matrix on a wall.

## Usage

1. Open `cap-wall-mount.scad` in [OpenSCAD](https://openscad.org/).
2. Adjust parameters at the top of the file.
3. Render (**F6**) and export to STL (**F7**).
4. Slice and print.
